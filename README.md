# Spotify Tracks Analysis Project

## Project Overview
This repository contains a collaborative Exploratory Data Analysis (EDA) of the Spotify Tracks Dataset. The project functions as a comprehensive data-analysis toolkit that investigates audio characteristics, popularity distributions, artist frequencies, and genre trends across over 113,000 tracks. The analysis relies strictly on statistical evaluation and data visualization without utilizing machine learning models.

## Directory Guide
* `data/`: Contains dataset source information and file requirements.
* `notebooks/`: Houses the four individual Google Colab Jupyter notebooks (.ipynb) utilized for code execution, data cleaning, and visualizations.
* `docs/`: Contains the formal Markdown reports detailing the specific findings, methodologies, and limitations for each analytical domain.
