# Methodology and Workflow
## Workflow Breakdown

1. **Data Cleaning & Deduplication**:
   - Filtered out unneeded index columns.
   - Cleared blank/missing rows across track attributes.
   - Converted song duration values from milliseconds (`duration_ms`) to seconds (`duration_sec`).

2. **Metric Aggregation**:
   - Calculated representation frequency across 113 unique genres.
   - Analyzed metric spreads for key features including danceability, energy, and track popularity.

3. **Data Visualization**:
   - Constructed genre representation bar plots.
   - Generated side-by-side distribution charts and audio feature boxplots.
